# 🎓 RUSSIAN SCHOLAR

An interactive full-stack Russian language mastery and survival platform designed specifically for international students, government scholarship holders, and **Open Doors** olympiad winners preparing for their academic journey in Russia.

---

## 🌟 Welcome to Russian Scholar
Moving to a new country is an exciting adventure, but navigating daily life in Russia requires functional, immediate survival language skills. Even if your university program is taught in English, daily activities—such as grocery shopping at *Pyaterochka*, finding your dormitory room, checking in at passport control, or buying medicine at an *Apteka* (pharmacy)—are conducted entirely in Russian.

**Russian Scholar** bridges this gap using advanced AI-driven conversational scenarios, real-time voice synthesis, interactive grammar lectures, vocabulary decks, and comprehensive alphabet training to raise your confidence before you even board your flight.

## 🚀 Core Features

### 1. 🗣️ Interactive Survival Voice Scenarios (AI Tutor)
Roleplay real-world dialogues with a persistent, context-aware AI tutor who guides you through five crucial survival stages per scenario:
* **🛒 Grocery Shopping at Pyaterochka:** Practice cashier loyalty card questions ("*Karta est'?*"), buying grocery staples, and checking out.
* **💊 Pharmacy Assistance:** Describe symptoms (colds, headaches) to get the correct over-the-counter medicine.
* **🎓 University Enrollment:** Submit registering documents, verify scholarship letters, and receive your student ID (*studencheskiy bilet*).
* **🚕 Taxi Booking & Airport Customs:** Speak with Yandex-style taxi drivers and border agents.
* **🏠 Dormitory Check-in:** Coordinate with dormitory commandants (*komendant*) and locate rooms.

### 2. 📝 Intelligent Grammar Correction
Our smart AI parser highlights grammatical errors immediately:
* **Emerald Grammar Cards:** If you make a mistake, our AI highlights correct Cyrillic spelling and usage in dedicated green help cards.
* **Visual Distinctions:** The interface color-codes grammar feedback separately from general conversation text to keep focus clean.

### 3. 🎙️ Natural Voice Synthesis (TTS) & Recognition
* **Audio Playback:** High-fidelity Russian Text-To-Speech (normal speed + half-speed slow play) for perfect accent practice.
* **Speech-To-Text:** English voice recognition input support for high-efficiency mobile/desktop entry.

### 4. 📚 Comprehensive Educational Tools
* **🔤 Interactive Alphabet Mastery:** Learn Cyrillic characters with visual guides, typing tests, and native audio.
* **⚡ Daily Word-of-the-Day:** Stay consistent with high-yield scholarship vocabulary delivered directly to your dashboard.
* **🎯 Grammar Lectures & Tests:** Engage with targeted lessons (noun genders, plurals, case systems) followed by interactive multiple-choice tests.
* **📈 XP and Achievements Engine:** Complete tasks to earn XP points, level up, and track your daily streak metrics.

## 🚀 Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) (v18 or higher) installed.

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/russian-scholar.git
   cd russian-scholar
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Configure environment variables in `.env` (refer to `.env.example`):
   ```env
   GEMINI_API_KEY=your_gemini_api_key
   VITE_FIREBASE_API_KEY=your_firebase_api_key
   # ... (Add remaining Firebase config variables)
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) to see the application.
